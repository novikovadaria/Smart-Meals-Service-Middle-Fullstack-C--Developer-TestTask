## SmsWpfApp

WPF-приложение на .NET 8.0 для просмотра и изменения переменных среды пользователя.

### Реализация

Используется паттерн MVVM

ViewModel реализованы с помощью CommunityToolkit.MVVM

Чтение списка переменных из appsettings.json

Значения читаются и сохраняются через EnvironmentVariableTarget.User

Переменные доступны другим приложениям и сохраняются после перезапуска ОС

### Работа с данными

Значения загружаются при старте приложения

Изменения сохраняются автоматически при завершении редактирования строки

В ОС записываются только изменённые переменные

Поддерживаются текстовые значения произвольной длины

### Логирование и ошибки

Используется Serilog

Все изменения и ошибки логируются

Логи сохраняются в папку:

```\bin\Debug\net8.0-windows\Logs```


Формат имени файла:

```test-sms-wpf-app-yyyyMMdd.log```
