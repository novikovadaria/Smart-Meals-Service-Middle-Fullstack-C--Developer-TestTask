### База данных

В ТЗ не указан предпочтительный способ доступа к СУБД.

Для работы с PostgreSQL используется Entity Framework Core как
стандартный и поддерживаемый ORM для .NET-приложений.

В рамках тестового задания применяется Database.EnsureCreated(),
так как схема базы данных фиксированная, не предполагается её эволюция
и не требуется контроль версий структуры.

В продакшн сценарии схема БД должна управляться централизованно.
В зависимости от процесса разработки возможны два подхода:

Code-First — с использованием миграций EF Core и вызова
Database.Migrate() для применения изменений схемы.

Database-First — когда база данных является источником истины,
а модели и DbContext генерируются автоматически с помощью
EF Core Scaffold (dotnet ef dbcontext scaffold).

### Конфигурация:
